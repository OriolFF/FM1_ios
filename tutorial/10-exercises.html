10. Build these sounds

Five guided exercises

These five exercises train the skills in the earlier pages. They use typical starting values, not measured ones: treat the numbers as a first guess, then adjust by ear. Do not hold SAVE until you like the result. If you pick another voice first, your changes vanish (which is also a way to start over).

Before you begin

Pick a voice you don’t mind overwriting, for example one in a bank you can reset. Each exercise starts with Init Voice so the starting point is always known: EDIT → black key GLO → SELECT to page 2 → turn KNOB 1 clockwise (details). We assume the DX7 init template: algorithm 1, only OP1 audible.

Exercise 1: Hear a modulator (the “wah” of FM)

Goal: understand that modulator level = brightness.

  1. Init Voice. Play a note: a plain sine.

  2. EDIT → OP2 (page 1). In algorithm 1, OP2 modulates OP1.

  3. Turn KNOB 4 (OutLevel) from 0 slowly up to about 70 while holding a key. The tone gets brighter, then rough.

  4. Now turn KNOB 2 (FreqCoarse) to 2, 3, 4. Whole numbers keep the pitch clean. Try FreqFine 50 on top: the tone goes bell-like and slightly out of tune.

What you learned: OP1 is the carrier (volume), OP2 the modulator (brightness), and the ratio decides the flavour.

Exercise 2: A bell / electric piano that mellows

Goal: give the modulator an envelope so the brightness fades while the note rings.

  1. Continue from Exercise 1 with OP2 FreqCoarse 14 (a classic bell-like ratio) and OutLevel about 70.

  2. Give OP1 (the carrier) a long ring: OP1 page 2, Rate 1 = 99, Rate 2 = 30, Rate 3 = 30, Rate 4 = 50; page 3, Level 1 = 99, Level 2 = 80, Level 3 = 0, Level 4 = 0. Level 3 = 0 makes the note die away on its own, like a struck bell.

  3. Give OP2 (the modulator) a faster decay than OP1: OP2 Rate 2 = 50, Rate 3 = 50, with Level 2 = 40 and Level 3 = 0. The sparkle disappears before the note does.

  4. Play a few notes and adjust. Lower OP2’s OutLevel a little for a softer electric piano, or raise Coarse for brighter metal.

  5. Optional: FX → Reverb on (K4 clockwise), Mix about 30%. Then hold SAVE.

Exercise 3: Feedback, from sine to saw to noise

Goal: hear what Feedback does by itself.

  1. Init Voice. Turn ALGORITHM to 32: all six operators are carriers, and the feedback sits on operator 6.

  2. OP1 is the only audible operator after Init. Switch the audible one: EDIT → OP6 → page 1: set OutLevel to 99, then OP1 OutLevel to 0 so only OP6 sounds.

  3. EDIT → black key GLO → page 1 → KNOB 2 Feedback. Turn it from 0 to 7 while playing: sine → buzzy → saw-like → noisy.

  4. For a bass: set Feedback about 4–5, EDIT → MONO, then OCT− twice. Set OP6 rates for a snappy decay (page 2: Rate 2 about 70).

Check which operator carries the feedback

The algorithm diagram shows a red loop on one operator; our table puts it on operator 6 for algorithm 32. If your sound does not react to Feedback, turn ALGORITHM and look at the popup: the operator with the loop is the one to make audible.

Exercise 4: Movement: vibrato and a slow pad

Goal: use the LFO and the global ADSR.

  1. Pick a sustained voice, e.g. 004 SYN PAD 1 (or 067 STRING 1).

  2. LFO page 1: Wave Sine, Speed about 40, PMD about 20. Page 2: Delay about 30, Pitch Sens 3 (it must be above 0), Key Sync on. Play a long note: vibrato fades in after a moment.

  3. Press ENV (LED on). Attack about 60%, Decay 30%, Sustain 80%, Release about 60%. Notes now swell in and fade out slowly.

  4. Press FX: switch on Chorus (K4 clockwise) with Depth about 40 and Mix about 50; add Reverb, Hall type.

  5. Hold SAVE.

Exercise 5: A pattern with the arpeggiator and the sequencer

Goal: make music without playing every note.

Arpeggiator (30 seconds)

  1. Choose a bell or pluck voice, e.g. 121 TUB BELLS or 001 PIANO 1.

  2. Press ARP. Mode Up, Octave 2, Rate 1/16, Tempo about 110. Hold a minor chord.

  3. Page 2 (turn SELECT): Gate 60%, Swing 60%, Latch ON. Release the keys: the arp keeps going. Change Mode to Inclusive or Random.

  4. Press ARP to switch off.

Sequencer: an 8-step bassline

  1. Choose a bass voice, e.g. 035 BASS 1. Press SEQ.

  2. Page 1: Pattern 1, turn Clear if it has old notes, set Step to 8.

  3. Press REC. Play, one note per step: C, C, G, C, Bb, C, G, F. The white-key LEDs fill up.

  4. For a rest: while recording, hold REC and turn SELECT to move past a step without playing anything on it.

  5. Press REC to stop, then PLAY/STOP. The loop plays. Page 2: Tempo 100, Gate 50%. Page 3: Swing 55%.

Experiments

Record pattern 2 as a variation and set page 1 Chain to 2 to hear both; give pattern 2 a different Voice on page 2; transpose the whole pattern on page 3.
