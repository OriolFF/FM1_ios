The M-VAVE FM-1, step by step

A hands-on guide to the pocket FM synthesizer: every knob, every button, every screen, written for a musician who has never programmed an FM synth.

The FM-1 is a small battery-powered synthesizer with 27 keys, a tiny colour screen, seven endless knobs and a volume knob. Inside is a six-operator FM engine of the kind made famous by the Yamaha DX7, with 32 algorithms, 128 voice memories (called presets on the panel and in the manual, voices in DX7 language), six effects, an arpeggiator and a 16-pattern step sequencer.

The screen is small and the buttons do many things, so the instrument looks harder than it is. Almost everything follows one pattern: press a mode button, turn SELECT to flip pages, turn KNOB 1–4 to change the four values on screen.

  1. SELECT flips pages.
  2. KNOB 1–4 change the four values on screen, top-left to bottom-right.
  3. The screen names each value and shows what it is set to.
  4. Mode buttons (FX, ENV, LFO, EDIT, GLO, ARP, SEQ…) decide what the knobs do. HOME always takes you back.
Which firmware does this guide cover?

The stock M-VAVE firmware, version V15 (released 30 July 2026): one voice at a time, 12-note polyphony, a 16-step sequencer. It does not cover the later V16 (multitimbral) firmware, the open FM1 Open groovebox firmware, or any third-party firmware. Where V14 and V15 differ, a blue note like this one says so.

How to read the pictures

Each step shows a redrawn screen mock-up. The four tiles carry small K1–K4 badges telling you which knob changes which tile. The footer bar (like 1/6 OP1 Tuning) is the page indicator: page 1 of 6.

On the panel drawings, orange rings with numbers show which control to touch, in order.

The numbers on the mock-ups are examples, not factory settings.

What this guide could not confirm

A few details are not written down anywhere we could find: for example the exact firmware-update button sequence and the full list of arpeggiator rates. Purple boxes like this one mark those places, and the reference page collects them all.

A note on the pictures

All diagrams and screens are redrawn from the manual's page tables. They are close to the real screen but not photographs, and exact fonts and colours differ slightly.
